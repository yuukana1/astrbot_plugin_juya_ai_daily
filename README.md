# 橘鸦AI日报推送

每日 AI 资讯自动推送插件 - 为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 开发

通过 RSS 订阅 [橘鸦 AI 日报](https://daily.juya.uk/rss.xml) 获取最新 AI 早报，将当期**全部更新**按原栏目顺序渲染为一张高清长图，自动推送到 QQ 群 / 私聊。

## ✨ 功能

- 📰 **每日自动推送**：每天定时（默认早 8:00）自动推送最新 AI 资讯
- 🖼️ **精美图片日报**：提取原始 RSS 的标题、导语、栏目和来源，按资讯卡片排版为图片
- 🔤 **开源中文字体**：默认版内置霞鹜文楷轻便版 Regular；无字体轻量版自动使用系统中文字体
- 🛡️ **明确失败提示**：图片渲染或发送多次失败后，仅发送对应的失败提示，不调用模型，也不发送 RSS 纯文本
- 🔄 **手动获取**：发送 `/AI日报` 随时获取最新 AI 资讯
- 📋 **灵活订阅**：支持配置文件填写群号/QQ号，也可在群聊或私聊中发送指令订阅
- ⏳ **智能轮询**：若 RSS 尚未更新当日内容，插件会自动间隔轮询直到获取到当日文章
- 🎯 **逐目标补发**：每个群聊/私聊独立记录投递结果，下一轮只补发失败目标，不会因其他群成功而漏发
- 💾 **缓存去重**：图片按文章缓存；投递进度原子落盘，重启后继续恢复
- 🪶 **轻量可靠**：复用 AstrBot 官方 `html_render`，不额外安装 Chromium/Pillow；共享 HTTP 会话，限制并发，并为渲染服务增加熔断保护
- 🧷 **手动防重复**：每条手动命令最多投递一次图片；按平台消息 ID 拦截同一事件的重复处理，不影响新的主动请求
- 🔎 **订阅状态明细**：状态指令按群聊和私聊分类列出具体 ID、机器人及订阅来源
- 📐 **无白边长图**：画布自适应渲染视口宽度，避免渲染服务视口变化产生右侧白边

## 🛡️ 图片失败处理

默认 `image_delivery_mode=auto` 时，每个目标独立执行：

1. 图片渲染最多尝试 3 次（指数退避）
2. 渲染 URL 图片发送最多尝试 3 次
3. 下载为插件数据目录中的本地 JPEG，再发送最多尝试 3 次
4. 渲染多次失败时发送“图片渲染失败”提示
5. 图片发送多次失败时发送“图片发送失败”提示

图片失败提示发送成功后，该目标本轮视为已处理；如果连失败提示也无法发送，目标会保留为待重试状态。

> 上述图片发送重试用于定时主动推送。手动 `/AI日报` 每条命令最多调用一次图片发送；遇到异常时发送对应失败提示，不会补发第二张图片。`manual_dedupe_seconds` 只拦截同一个平台消息事件被重复处理，不会阻止新的手动命令，也不会与定时推送互相影响。

## 📝 指令列表

| 指令             | 说明                              |
| ---------------- | --------------------------------- |
| `/AI日报`     | 立即获取最新一期完整图片日报       |
| `/AI日报订阅` | 订阅每日推送（群聊/私聊均可使用） |
| `/AI日报退订` | 取消每日推送订阅                   |
| `/AI日报状态` | 查看推送状态与订阅信息             |

`/AI日报` 不发送处理中提示，最终只发送日报图片、图片渲染失败或图片发送失败。

## ⚙️ 配置说明

安装插件后，在 AstrBot 管理面板中可配置以下选项：

| 配置项                             | 说明                                                              | 默认值 |
| ---------------------------------- | ----------------------------------------------------------------- | ------ |
| `push_hour` 每日推送时间（小时）   | 0-23，设定首次检查 RSS 的小时                                     | 8      |
| `push_minute` 每日推送时间（分钟） | 0-59，设定首次检查 RSS 的分钟                                     | 0      |
| `rss_poll_interval` RSS 轮询间隔   | 当 RSS 尚未更新当日内容时，每隔多少秒重新检查一次（默认 10 分钟） | 600    |
| `timezone` 调度时区 | IANA 时区名称；默认按中国标准时间调度 | Asia/Shanghai |
| `enable_image_render` 图片日报 | 是否启用图片渲染；关闭或失败时发送渲染失败提示 | true |
| `image_quality` JPEG 质量 | 70-95；默认 90，兼顾长图文字清晰度与图片体积 | 90 |
| `image_delivery_mode` 图片发送方式 | `auto`：URL 失败切本地；也可强制 `url` 或 `local` | auto |
| `render_max_retries` 渲染尝试次数 | 包含首次尝试 | 3 |
| `send_max_retries` 发送尝试次数 | 每种发送方式各自的最大尝试次数 | 3 |
| `retry_base_delay` 重试等待 | 以此为基础执行指数退避 | 2.0 |
| `render_timeout` 渲染超时 | 单次 HTML 渲染超时秒数 | 45 |
| `render_circuit_failure_threshold` 熔断阈值 | 连续失败多少轮后暂时跳过渲染 | 3 |
| `render_circuit_minutes` 熔断时长 | 熔断期间跳过图片并发送渲染失败提示 | 30 |
| `send_concurrency` 发送并发数 | 2C2G 服务器建议维持默认值 | 3 |
| `manual_dedupe_seconds` 手动防重复 | 同一个平台命令事件重复触发时的去重时间窗口 | 60 |
| `image_cache_days` 本地图片保留 | URL 失败时下载的 JPEG 保存天数 | 7 |
| `subscribed_groups` 订阅群号       | 手动填写需要推送的 QQ 群号，每行一个                              | 空     |
| `subscribed_users` 订阅 QQ 号      | 手动填写需要私聊推送的 QQ 号，每行一个                            | 空     |

## 📦 快速部署

### 方式一：AstrBot 插件市场（推荐）

1. 打开 AstrBot WebUI → **插件** → **插件市场**。
2. 搜索 **橘鸦AI日报推送** 或 `astrbot_plugin_juya_ai_daily`。
3. 点击安装并启用；修改配置后可在插件卡片菜单中点击“重载插件”。

### 方式二：Git 克隆

在 AstrBot 插件目录执行：

```bash
cd /path/to/AstrBot/data/plugins
git clone https://github.com/yuukana1/astrbot_plugin_juya_ai_daily.git
```

Windows PowerShell 示例：

```powershell
cd C:\path\to\AstrBot\data\plugins
git clone https://github.com/yuukana1/astrbot_plugin_juya_ai_daily.git
```

重启 AstrBot，或在插件管理页执行“重载插件”。

### 方式三：上传 ZIP

在 AstrBot WebUI → **插件** → **已安装** → **安装插件** → **从文件安装**，选择 GitHub Release 中下载的 ZIP 文件。压缩包内应直接包含 `main.py`、`metadata.yaml` 和 `_conf_schema.json`。

| 安装包 | 字体 | 适用场景 |
| --- | --- | --- |
| `astrbot_plugin_juya_ai_daily_v1.0.0.zip`（默认） | 内置霞鹜文楷轻便版 Regular | 希望日报外观稳定一致 |
| `astrbot_plugin_juya_ai_daily_v1.0.0_lite.zip` | 不含字体，使用系统字体 | 更小的安装包和渲染请求 |

本版本使用 AstrBot 官方 HTML 渲染和消息发送接口，要求 AstrBot `>=4.5.7`；不调用 LLM。

## 📌 注意事项

- 图片链路失败时只发送对应的失败提示，不调用 LLM，也不发送完整 RSS 纯文字版
- 插件在重启后会自动补偿检查：若已过推送时间且当天未推送，会立即尝试拉取并推送
- 指令订阅同时支持群聊和私聊：在希望接收日报的会话中发送 `/AI日报订阅` 即可
- 两种订阅方式（配置文件 + 指令）可同时使用，插件会自动合并去重
- 投递状态按文章和目标分别记录，最多保留最近 30 期；本地图片默认保留 7 天
- 图片日报依赖 AstrBot 的 HTML 渲染服务；服务不可用时会发送渲染失败提示
- 每期 RSS 的全部新闻会按原栏目顺序合并到一张长图，不截取、不分页
- 默认字体版仅在实际渲染时读取字体并临时编码，不会常驻内存；无字体轻量版不产生字体编码开销
- 内置字体为霞鹜文楷轻便版 v1.522，依据 SIL Open Font License 1.1 再分发，详见 [第三方声明](THIRD_PARTY_NOTICES.md)
